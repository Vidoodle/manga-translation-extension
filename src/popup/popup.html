Create an OpenRouter key

Firefox saves your key on this computer so you don’t have to enter it again. Only save it on a computer you trust.

Keeping your key safe

Use your own password-protected computer account. Don’t save a key on a public computer or a login shared with people you don’t trust.

Create a key just for this extension and set a low spending limit in OpenRouter’s key settings. If you think it has been copied, delete it there and create a new one. Removing it from this extension doesn’t disable a copied key.

The saved key isn’t encrypted. Someone who can read your Firefox files could copy it and use your OpenRouter credits.
